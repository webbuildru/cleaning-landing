# Cleaning

Powder-blue surfaces echo the upholstery in the photographs. Royal blue marks actions against light backgrounds, deep blue is reserved for text. Use Manrope for headings and Golos Text for body copy.

Keep the first screen focused on the photograph, service and next action. The 3D demonstration should read as a studio space with a separate set of rotation buttons. Show changes directly on the fabric and use the progress indicator only to summarize the interaction. The booking form pairs a navy introduction with a light, high-contrast form.
