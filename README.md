# Cleaning — выездная химчистка мебели

Адаптивный лендинг службы выездной химчистки диванов, кресел и матрасов. На странице есть услуги и цены, этапы чистки, сравнение «до и после», калькулятор и форма заявки.

## Интерактивный 3D-диван

- Стрелки ← и → поворачивают диван, а ↑ и ↓ меняют высоту ракурса. Кнопки доступны с клавиатуры.
- Чтобы стереть пятна, начните движение пальца на пятне или проведите курсором с зажатой левой кнопкой мыши. Свайп за пределами пятен прокручивает страницу. Шкала показывает процент чистоты.
- Кнопка **«Убрать пятно»** стирает одно пятно за нажатие. **«Сбросить»** возвращает пятна и исходный ракурс.
- Сцена загружается при приближении к 3D-блоку. На устройствах без WebGL 2 отображается статичное изображение дивана.

## Калькулятор и форма заявки

Калькулятор умножает базовую цену выбранной услуги на количество предметов и показывает ориентировочную стоимость. Ссылка под расчётом открывает форму с уже выбранной услугой.

Кнопка **«Отправить»** проверяет обязательные поля и формат телефона в браузере. После проверки введённый текст остаётся в полях. Форма не отправляет сетевые запросы и не записывает данные в хранилище.

## Локальный запуск

Готовая страница находится в `dist/`. Откройте `dist/index.html` или запустите HTTP-сервер из корня проекта:

```sh
python -m http.server 4173 --directory dist
```

Страница будет доступна по адресу `http://localhost:4173`.

## Сборка и структура

Страница написана на HTML, CSS и JavaScript. Модель работает на Three.js, а esbuild собирает её в отдельный браузерный файл. Для пересборки после изменения модели нужны Node.js и npm.

```sh
npm install
npm run build:3d
```

- `dist/index.html` — разметка и контент лендинга.
- `dist/style.css` — стили и адаптивная раскладка.
- `dist/site.js` — калькулятор, проверка формы и загрузка 3D-сцены.
- `src/sofa.js` — исходный код модели, управление ракурсом и очистка пятен.
- `dist/sofa.bundle.js` — готовая сборка модели.
- `dist/assets/` — изображения, шрифты и лицензии на шрифты и Three.js.

Для публикации достаточно каталога `dist/` со всеми файлами внутри. Сервер приложений и переменные окружения не требуются.

Фотографии сгенерированы для этого лендинга. Сравнение «до и после» иллюстрирует результат химчистки.
